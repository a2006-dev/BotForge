## 1. 颜色系统

### 1.1 品牌与基础色

品牌意象：蓝色鲸鱼，气质温和、可靠、略带俏皮但不幼稚。
种子色采用海蓝系，通过 Material 3 动态取色生成亮/暗两套方案。

| Token | 用途 | 备注 |
|---|---|---|
| `primary` | 主操作、强调 | 动态取色主色，低版本用品牌海蓝 |
| `onPrimary` | 主色上的文字 | 对比度 ≥ 4.5:1 |
| `primaryContainer` | 选中态底色、Chip 背景 | |
| `secondary` / `tertiary` | 次级强调 | 谨慎使用，不做状态色 |
| `surface` | 页面底色 | 与 `surfaceContainer` 形成层级 |
| `surfaceContainerLowest/Low/High/Highest` | **tonal elevation 五级** | 层级优先用它，不用阴影 |
| `outline` / `outlineVariant` | 分割线、边框 | `outlineVariant` 用于 hairline |

### 1.2 语义状态色（独立 token，禁止用品牌色表达状态）

提示词 §4.1 要求 6 种状态。当前代码 `BotConnState` 有 6 个枚举值，但语义需重新映射：

| 提示词状态 | 含义 | 对应 `BotConnState` | 色调 | 必配元素 |
|---|---|---|---|---|
| 在线 | 已连接且心跳正常 | `CONNECTED` | success 绿 | 图标 + 文字「在线」 |
| 连接中 | 建立中/等待就绪 | `CONNECTING`、`AUTHENTICATING` | info 蓝 | 图标 + 呼吸脉冲 |
| 重连中 | 断线自动重连 | `RECONNECTING` | warning 橙 | 图标 + **倒计时「N 秒后重试」** |
| 异常 | 需用户处理 | `ERROR` | danger 红 | 图标 + 原因 + 修复入口 |
| 已暂停 | 用户主动停止 | `STOPPED`（且 `userStopped == true`） | neutral 灰 | 图标 + 「已暂停」 |
| 离线 | 无网络 / 服务未运行 | `STOPPED`（且 `userStopped == false`） | neutral 灰 | 图标 + 「离线」 |

> **实现要点**：`STOPPED` 需拆成「已暂停」与「离线」两种文案，判定依据是 `Config.userStopped`。
> 这是当前代码缺失的一块（见 §6.1 改动清单）。

状态色必须同时提供前景/背景成对值，禁止用同一色值画文字和底色：

```kotlin
enum class StatusTone(val fg: Color, val bg: Color) {
    Success(Color(0xFF2E7D5B), Color(0xFFE3F3EC)),
    Info   (Color(0xFF2C6BB3), Color(0xFFE5EFFA)),
    Warning(Color(0xFF9A5B00), Color(0xFFFDF0DC)),
    Danger (Color(0xFFB3261E), Color(0xFFFBEAE8)),
    Neutral(Color(0xFF5A5F66), Color(0xFFEDEFF2)),
}
```

暗色模式下必须重新取值，不能复用亮色值（对比度会不足）。

### 1.3 对比度硬约束

所有文字/背景组合 **≥ 4.5:1**，大号文字（≥ 18sp 或 ≥ 14sp bold）≥ 3:1。
实现时用 `ColorUtils.calculateContrast()` 在单元测试里断言，不靠肉眼。

## 2. 字体与排版

### 2.1 层级（Material 3 Typography 映射）

| 用途 | 样式 | 字号 | 字重 |
|---|---|---|---|
| 页面大标题（折叠 TopAppBar） | `displaySmall` | 28sp | Medium |
| 区块标题 | `titleMedium` | 16sp | Medium |
| 列表主文本 | `bodyLarge` | 16sp | Normal |
| 列表副文本 | `bodyMedium` | 14sp | Normal |
| 说明/注释 | `bodySmall` | 12sp | Normal |
| 按钮 | `labelLarge` | 14sp | Medium |
| 标签/Chip | `labelMedium` | 12sp | Medium |

**正文字号最小 14sp**（提示词 §4.2）。说明性文字可用 12sp，但不得用于可读内容。

### 2.2 等宽数字（当前缺失，必须补）

提示词 §4.2：运行时长、计数、延迟必须用 **`tnum`**，避免数字宽度变化导致跳动。

```kotlin
/** 所有数字型指标的统一样式：等宽数字，避免刷新时抖动 */
val NumericStyle = TextStyle(
    fontFeatureSettings = "tnum",
    fontFamily = FontFamily.Monospace,  // 延迟/时长/日志用等宽
)
```

适用位置：心跳间隔、ACK 延迟、运行时长、重连次数、在线数、消息数、倒计时。

### 2.3 字体缩放

支持系统字体 **200%** 不破版：
- 禁止对可读文本使用 `maxLines = 1` 硬截断
- 长文本用换行或「展开」折叠
- 固定高度容器改为 `wrapContentHeight` 或 `heightIn(min = ...)`

### 2.4 等宽场景

日志、命令、ID、openid、Token 前缀 → `FontFamily.Monospace`，并提供复制按钮。

## 3. 间距、形状、层级

### 3.1 间距（4dp 基准网格）

| Token | 值 | 用途 |
|---|---|---|
| `xxs` | 2dp | 图标与文字微间距 |
| `xs` | 4dp | 紧凑间距 |
| `sm` | 8dp | 组内元素间距 |
| `md` | 12dp | 卡片内边距、组间间距 |
| `lg` | 16dp | **屏幕左右边距** |
| `xl` | 20dp | 区块间距 |
| `xxl` | 24dp | 大区块分隔 |
| `huge` | 32dp | 页面级留白 |

禁止在页面里写 `13.dp` / `7.dp` 这类魔法数字（当前 `Dimen.kt` 已有此约束，继续保持）。

### 3.2 圆角层级

| Token | 值 | 用途 |
|---|---|---|
| `xs` | 8dp | Chip、小标签 |
| `sm` | 12dp | 输入框、按钮 |
| `md` | 16dp | 卡片 |
| `lg` | 20dp | 大卡片、Sheet 顶部 |
| `xl` | 28dp | BottomSheet、对话框 |
| `full` | 999dp | 状态胶囊、圆形头像 |

### 3.3 层级（tonal elevation 优先）

提示词 §4.3：层级用**色调**而非阴影。
- 页面底色 `surface`
- 卡片 `surfaceContainerLow`
- 悬浮/选中 `surfaceContainerHigh`
- Sheet `surfaceContainerHighest`

阴影仅用于真正浮起的元素（FAB、Snackbar），且透明度 ≤ 8%。

## 4. 动效规范

| 类型 | 时长 | 缓动 | 示例 |
|---|---|---|---|
| 微交互 | 100–150ms | `FastOutSlowIn` | 开关、按压、Chip 选中 |
| 元素进出 | 200–250ms | emphasized decelerate | 卡片出现、Snackbar |
| 页面转场 | 300ms | emphasized | 页面切换 |
| 状态脉冲 | 1200–1600ms 循环 | ease-in-out | 「连接中」呼吸点 |

### 4.1 必须响应的系统设置

```kotlin
// 尊重「移除动画」
val reduceMotion = LocalAccessibilityManager.current != null &&
    Settings.Global.getFloat(contentResolver, Settings.Global.ANIMATOR_DURATION_SCALE, 1f) == 0f
```
开启时：所有非必要动画降为瞬时切换，脉冲改为静态圆点。

### 4.2 状态变化的一次性反馈

上线/掉线时**只震一次**，不要连续震动：

```kotlin
// 状态跃迁检测，只在真变化时触发
LaunchedEffect(state) {
    if (prev != null && prev != state) haptic.performHapticFeedback(HapticFeedbackType.LongPress)
}
```

### 4.3 列表

`LazyColumn` 增删用 `Modifier.animateItem()`（Compose 1.6+）或 `animateItemPlacement`，避免跳变。

## 7. 图标规范

- 优先使用 `material-icons-core` 内置图标（体积小）
- 缺失的图标自绘 `ImageVector`，不引入 `material-icons-extended`（体积大）
- 若必须引入 extended，**必须同时开启 release R8 压缩并配置 keep 规则**（当前 `minifyEnabled false`）
- 图标与文字并存，不只靠图标传达状态
- 图标尺寸：列表内 20dp，状态区 24dp，按钮内 18dp
