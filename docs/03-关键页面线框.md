│                                          │

**规格要点**

- 行高自适应，长文案换行不截断（日志的价值在细节，省略会丢信息）

- 自动滚动到底：用户手动上滑时暂停，回到底部时恢复
- 导出：生成 txt 到 `Downloads`，Snackbar 提示路径
- 空态：「暂无日志」

## 8. 危险操作确认 Sheet（L2 / L3）

通用组件，所有危险操作复用。

```
┌──────────────────────────────────────────┐
│                 ────                     │  拖拽指示
│                                          │
│  ⚠  卸载「系统控制」？                   │  titleLarge
│                                          │
│  该插件声明了 L3 级权限，卸载后它的数据  │
│  与配置将一并清除，无法恢复。            │
│                                          │
│  最近调用记录将保留在审计日志中。        │
│                                          │
│  ┌────────────────────────────────────┐  │
│  │          取消                      │  │  text 按钮
│  ├────────────────────────────────────┤  │
│  │          确认卸载                  │  │  danger filled
│  └────────────────────────────────────┘  │
└──────────────────────────────────────────┘
```

**分级规则**（对应提示词 §8）

| 级别 | 示例 | 确认方式 |
|---|---|---|
| L0 | 读取状态、查日志 | 无需确认 |
| L1 | 网络请求、读取文件 | 无需确认 |
| L2 | 写入文件、发消息 | 一次确认（Sheet） |
| L3 | 执行命令、卸载插件、删除机器人 | Sheet + 输入名称核对 |
| L4 | 清空数据、重置全部配置 | Sheet + 名称核对 + 3 秒倒计时 |

L3 的输入核对：需手动输入插件名（或机器人名）才启用确认按钮。

## 10. 状态语义与视觉映射

对应提示词 §4.1 的 6 种状态，线框中所有状态文字/Pill 均取此表：

| 状态 | 触发条件 | 文字 | 色相 |
|---|---|---|---|
| 在线 | 服务运行且连接正常 | 在线 | success（绿） |
| 连接中 | 首次建立连接 | 连接中 | info（蓝） |
| 重连中 | 断线后重连，代数 ≥ 2 | 重连中 | warn（琥珀） |
| 异常 | 连续失败 ≥ 3 次 / 鉴权失败 | 异常 | danger（红） |
| 已暂停 | `Config.userStopped = true` 且服务在跑 | 已暂停 | neutral（灰） |
| 离线 | 服务未运行 | 离线 | neutral（灰，更浅） |

> 「已暂停」与「离线」必须区分：前者是用户主动停，后者是没在跑。当前实现里两者都显示 STOPPED，是待修项（见《01-设计规范》§6 差异清单）。

## 11. 关键交互时序

### 11.1 点「停止服务」

```
点按 → 立即置 Config.userStopped = true
     → 发 ACTION_STOP → stopSelf
     → onDestroy 读 canAutoRestart() = false
     → 不排重启
     → UI 收到 BotStatusRegistry 推送 → 状态变「已暂停」
```

**无确认弹窗**（停止是安全操作，可随时重启）。这是已实现的逻辑。

### 11.2 点「启动服务」

```
点按 → Config.userStopped = false
     → startForegroundService
     → 状态「连接中」→ 建立 WS → 「在线」
     → 失败重试，UI 显示「重连中」与代数
```

按钮在请求期间进入 loading 态并禁用，防重复点击。

### 11.3 收到新日志

```
Logger.i/w/e → 写磁盘 + 触发 listener
            → DashboardStore.onLogLine(line)
            → events = (line + old).take(6)，logTotal + 1
            → StateFlow 发射 → Compose 重组
```

**无轮询参与**。15 秒兜底仅刷新 persona/model 列表这类无推送源的数据。

## 12. 验收清单

- [ ] 6 种状态在真机可全部复现，且视觉可区分（尤其已暂停 vs 离线）
- [ ] 首页首屏（360×640 可视区）内可见 StatusHero + 主操作 + 至少 3 条事件
- [ ] 异常为 0 时 AttentionCard 不占任何高度
- [ ] 未启动时首页不出现统计数字区
- [ ] 新日志到达时首页事件区**无需等待**即更新（真机实测，非编译通过）
- [ ] 点停止后等 30 秒，服务不会自行拉起（真机实测）
- [ ] 自动拉起开关关闭后，杀进程也不拉起；开启后 10 秒内拉起
- [ ] L3 操作必须输入名称核对才能执行
- [ ] 空壳页不出现任何伪造数据
- [ ] 亮/暗双主题下所有语义状态对比度 ≥ 4.5:1
